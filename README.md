# Playbit アプリの一覧（正本）

Playbit の各 Shopify アプリの管理画面にある「おすすめアプリ」が読む一覧です。**ここだけ直せば、各アプリが取りに来ます**（最長24時間、再デプロイは要りません）。

公開先（GitHub Pages）: <https://playbit-team.github.io/playbit-apps-catalog/apps.json>

載せているのは App Store で公開済みの情報だけです（アプリ名・紹介文・ハンドル・アイコン）。

## 直し方

1. `apps.json` を直す（`updatedAt` も今日の日付に）。
2. アイコンを足すときは、1200×1200 の掲載アイコンから 128px の PNG を作って `icons/<id>.png` に置く。
   ```
   sips -s format png -Z 128 app-icon.png --out icons/<id>.png
   ```
3. `main` に push。GitHub Pages が出し直します。各アプリは次に取りに来たとき（最長24時間）に反映します。急ぐときは、そのアプリを再デプロイしてください。

## 書き方の決まり

Shopify App Store の要件に合わせています（2026-10-09 時点）。

- **値段を書かない**（4.2.3）。「無料インストール」も書きません。App Store の掲載ページに任せます。
- **数字の実績・保証・最上級の表現を書かない**（4.3.3）。「No.1」「唯一」「○%削減」など。
- **公開していないアプリは `handle` を空文字にする**。各アプリは `handle` が空のものを出しません。先に書いておいて、公開したらハンドルを入れるだけにできます。

## 項目

| 項目 | 決まり |
|---|---|
| `id` | 小文字の英数字とハイフン、40字まで。アイコンのファイル名にも使う |
| `name` | 60字まで |
| `summary` | 160字まで。一文 |
| `handle` | App Store のハンドル（`https://apps.shopify.com/<handle>`）。未公開は空文字 |
| `icon` | このリポジトリの `icons/` の URL。各アプリは同じ `id` のアイコンを同梱していれば、そちらを先に使う |

一覧は20件まで。各アプリは取ってきた中身を上の決まりで確かめ、合わないものは捨てます。取りに来られなかったときは、各アプリに同梱した控えを使います。

## 読んでいるアプリ

- shopify-app-delivery-date（Playbit 配送日時）
- shopify-app-cod（Playbit 代引き）

足したら、ここに書き足してください。
